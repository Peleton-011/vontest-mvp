### ✅ **24/05/25 Informe de Desarrollo**

El desarrollo de Vontest avanza de forma sostenida y estructurada, consolidando tanto las funcionalidades visibles como las bases técnicas que permitirán escalar la plataforma con solidez y coherencia. En esta etapa, se ha completado con éxito el **ciclo central de participación colectiva**, desde la creación de preguntas hasta la votación y presentación de resultados, todo bajo una arquitectura modular y segura.

La pieza restante, el foco del siguiente ciclo de desarrollo que convertirá el proyecto **en un prototipo maduro y plenamente funcional**, es el sistema de debate y discusión dentro de una misma propuesta, cubriendo todo el flujo de toma de decisiones. Esta sección incluirá soporte para conversaciones anidadas, adjuntar evidencias o estudios, e integrar formatos específicos para enriquecer la discusión colectiva. La arquitectura base ya está en su sitio, y la mayoría de las funcionalidades principales han sido diseñadas con extensibilidad en mente.

Paralelamente, se han implementado **todas las operaciones CRUD** para Vontests y propuestas. Es decir, los usuarios pueden no solo crear, sinó también editar, actualizar y eliminar tanto Vontests como propuestas, y **toda esta lógica está encapsulada en composables** reutilizables. Esto permite separar claramente las responsabilidades del código y mantener una arquitectura limpia. Además, se ha configurado las relaciones entre tablas de la base de datos para que **las eliminaciones sean en cascada a nivel de base de datos**: al borrar un Vontest se eliminan automáticamente sus propuestas, y al eliminar una propuesta se eliminan todos sus votos asociados.

Una de las tareas más complejas y demandantes del desarrollo ha sido la integración del **editor de texto enriquecido** personalizado, utilizado tanto para las descripciones de los Vontests como para las propuestas. Inicialmente fue diseñado para generar Markdown, pero tras una serie de pruebas y necesidades emergentes, se optó por un sistema basado en **HTML como formato interno**, que permite una mayor personalización visual, estructuración avanzada y una experiencia de escritura más rica. Esta decisión también abre la puerta a funcionalidades futuras como insertar imágenes, tablas, enlaces o anotaciones dentro de las propuestas. Este editor ha representado, hasta ahora, la inversión de tiempo más significativa en una sola funcionalidad del proyecto.

En cuanto a la participación, se continúa implementado un **sistema de votación por puntos acumulativos**: los usuarios reciben una cantidad fija de puntos (por ejemplo, 10) que pueden repartir entre las propuestas disponibles.  Esto permite una expresión más matizada de las preferencias colectivas que el típico voto binario. A nivel técnico el sistema asegura que se utilicen exactamente todos los puntos antes de permitir el envío, y los datos se almacenan con garantías de integridad mediante upsert y restricciones únicas por combinación de usuario y propuesta. Si bien este sistema de votación es funcional, ya se está pensando en ampliar las opciones, incluyendo votación por orden de preferencia (*ranked choice*) u otros modelos deliberativos.

A nivel de frontend, se ha priorizado la creación de **componentes reutilizables** como formularios, tarjetas, modales y menús de opciones, y todo el código se estructura siguiendo principios de escalabilidad y separación de responsabilidades.

En esta misma línea, se ha dedicado un esfuerzo considerable al desarrollo de **composables reutilizables**. Toda la lógica de interacción con la base de datos —crear, editar, eliminar y actualizar Vontests y propuestas— está encapsulada en composables que permiten mantener el código limpio y bien organizado. Además, se han creado composables para paginación, búsqueda con debounce, validación de roles, y manejo de sesiones, lo que representa una de las partes más sólidas y reusables de la arquitectura actual. Estas herramientas se reutilizan en distintas partes de la app —por ejemplo, en el dashboard y en la vista de propuestas— y constituyen una base sólida para futuras extensiones (filtros, ordenamientos, etc.).

La **página de resultados** ya presenta las propuestas ordenadas por puntuación total, y se están diseñando visualizaciones gráficas mediante gráficos de barras y componentes colapsables. Está previsto incorporar nuevas formas de mostrar resultados, resúmenes interpretativos y ciclos de retroalimentación para fomentar mejoras iterativas y aprendizajes colectivos.

En resumen: **la base técnica y funcional de Vontest se va asentando firmemente**. El proyecto ha alcanzado un hito importante: ya disponemos de un sistema operativo de deliberación y votación colectivo, con persistencia de datos, seguridad robusta y una estructura modular lista para ser testeada públicamente y seguir evolucionando. Lo que se está construyendo no es solo una aplicación, sino un sistema de deliberación pragmático, democrático y extensible, diseñado desde el inicio para evolucionar. Y lo que es más: está progresando con fuerza.
